Look-ahead and methodology notes
--------------------------------
- Returns use only the immediately preceding same-ticker observation.
- No future observations are used for filling, scaling, normalization, filtering, or feature construction.
- The 60-observation rule uses each ticker's full target-sample record count. It establishes regression feasibility; later rolling code must still use only observations strictly before date t to estimate beta_(i,t-1).
- Occasional calendar gaps remain as gaps. No missing return is replaced with zero.
- Extreme returns are retained. They require case-by-case review before any later error correction.
- The factor archive is the currently downloaded Kenneth French vintage. Historical factor values can be revised, so exact paper-vintage replication may require an archived release from the paper's era.
