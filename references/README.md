# Reference Code

The official paper repository is intentionally not vendored here. It is approximately
1.5 GB after checkout, has its own Git history, and uses a custom non-commercial license.

To restore the inspected reference checkout:

```bash
git clone --depth 1 https://github.com/gregzanotti/dlsa-public.git references/dlsa-public
```

Our implementation under `src/` is independent. See `docs/OFFICIAL_CODE_MAP.md` for the
mapping between paper concepts, official files, and this baseline.
